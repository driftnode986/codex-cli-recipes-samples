# AGENTS.md のテンプレート

第3章「AGENTS.md とコンテキスト設計」で扱った出発点をそのまま置いています。
**まるごとコピーせず、自分のプロジェクトに当てはまる行だけ**を写してください。

判断の基準は「これを外したら Codex の出力が悪くなるか」です。悪くならない行は削れます。

## それぞれの用途

- `minimal/` — まず置くならこれ（第3章 3-2）。5行から始めて、困ったときに追記していきます
- `typescript/` — TypeScript / Node.js の例（第3章 3-20）
- `python/` — Python の例（第3章 3-20）
- `with-claude-code/` — Claude Code と併用する場合（第9章 9-3）

## `with-claude-code/` について

Claude Code は `CLAUDE.md` を読み、`AGENTS.md` は読みません。同じ内容を2つのファイルに
書くと、片方だけ更新したときに2つのツールが違う前提で動きます。

そこで `CLAUDE.md` にはインポート1行だけを書き、共通ルールの実体は `AGENTS.md` 1つに
まとめます。この構成は第9章で両方のツールに同じ質問を投げて動作を確認しています。

```
your-repo/
├── AGENTS.md     ← 共通ルールの実体（Codex CLI がこれを読む）
└── CLAUDE.md     ← @AGENTS.md の1行 + Claude Code 固有の指示
```

シンボリックリンク（`ln -s AGENTS.md CLAUDE.md`）でも同じことができますが、Windows では
作成に管理者権限か開発者モードが要ります。本書はインポート方式を推奨しています。

すでに `CLAUDE.md` だけがあるリポジトリに Codex を後から入れる場合は、逆向きの設定が
第3章 3-9 にあります。どちらの方向でも、**実体を1つにする**という原則は同じです。

## サイズの上限に注意

`AGENTS.md` はセッションのたびに読み込まれます。既定で 32 KiB を超えた分は
**警告なく切り捨てられます**（第3章 3-7 で実測）。長くしすぎないでください。
